For target year y, train on all origin rows 1950..y-2; recent window y-6..y-2. Laplace all-history and recent base rates (1+positives)/(2+n). Country-history model shrinks all available country-specific training rows toward recent global probability with k=20. Prior-five-year model: indicator of at least one coded positive among observed origin rows y-6..y-2. For each training row z, compute that indicator using z-6..z-2, never its label or later information. Group training rows start in 1956, end y-2, and use only cases with at least one observed prior row. Partial history uses observed membership rows only; no observed prior row falls back to recent global. Group rate shrunk toward recent global with k=20. No filling nonexistent states with zero observations. All forecasts use identical Jan-1 risk set for each target year 1980..2024.
