# Fixed-roster score sensitivity — protocol 2026-11-27

After observing membership-only results, before computing scores for this variant. Reuse 1980–2024 historical outcome panel and fixed calibrated models, no tuning. For each origin y use Dec31 membership y-1 or y-3. Training remains the original dated Jan1 country-year panel through y-2, recent window y-6..y-2, shrinkage 20. Construct test rows for every frozen member, no use of target labels in prediction or calibration; constrain each model to recent baseline mean on its entire fixed roster. Compare paired Brier and log-loss gain against that baseline.

Use strict original Jan1-panel label only for overlapping countries. Any fixed code absent from Jan1 panel is unknown even if it entered later; no implicit zero. Report known-subset gain separately (retrospective conditional diagnostic, not prospective skill). For unknown labels compute exact worst/best total paired loss gains over every binary assignment independently, with denominator the entire fixed roster. Bounds are mathematical sensitivity ranges, not confidence intervals and not assertions that an absent sovereign executive could have a coup. Omitted newly admitted countries are outside this estimand. Known panel labels retain the original dated membership rule, including competing exit. A prospective fixed-cohort endpoint still requires independent code and executive-status adjudication; no 2025/2027 labels are inspected here.

The original retrospective sample was used to develop the models, so even positive lower bounds do not establish independent performance. No forecasts, no changes to published predictions. Results pending CI.
