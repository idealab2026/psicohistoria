# COUP2027 prospective resolution — proposed contract (2026-11-27)

Draft on separate development branch, not adopted or an issuance. Parent COUP2025 experiment remains in CI. The 2024 COW roster is a fixed 195-code cohort, not official 2027 membership. Primary endpoint: at least one overt failed or successful coup recorded in a complete future Powell–Thyne archive for the exact frozen COW code and valid date 2027-01-01 through 2027-12-31. Do not equate this operational source-record endpoint with all true events. COW v2024 ends December 2024 (https://correlatesofwar.org/data-sets/state-system-membership/). The author notes tentative data and future revisions (https://jonathanmpowell.com/coups/). Cline is an alternative endpoint, not interchangeable; its original data bytes remain unadmitted.

## Before issue

Freeze cohort, exact models (global_recent, country_constrained, prior5_constrained), feature lag, training-data end 2025 and any historical-to-2025 endpoint bridge explicitly; source archive must be dated and demonstrably available before issue. Do not silently substitute 2024 for 2025, or add 2026 data. Both calibrated models and reference stay fixed irrespective of 2025 scores. Require the previous PR to be consolidated, source/coverage audit, reviewed code crosswalk and prospective issuance protocol on main before candidate generation. Canonical issuance bytes contain target year, cohort snapshot, training cutoff, endpoint ID, one probability per model per code, issue time in UTC, and explicit source hashes. A separate public publication receipt pins the issue SHA and actual publication time strictly before 2027-01-01T00:00:00Z. Hash validation is not independent notarization; actual receipt must be verified, not invented from document metadata. No candidate generated by this contract.

## After the target year

No official scoring before 2028-03-01 UTC (administrative review window, not a claim that data will be ready then). First subsequently released, date-stamped author archive with explicit full 2027 coverage, recorded byte hash and reviewed completeness, schema, coding and state/code mapping is the primary target vintage. Source admission must be independently reviewed and append-only; do not choose a release based on scores. If evidence of completeness is unavailable, wait rather than assign negatives. Later revisions are distinct sensitivity results, not replacements of primary resolution. Record an explicit unknown for any unresolved country/code or missing coverage. A 0 means no matching coded event in a reviewed, covered country. Do not conflate an unverified status with 0. Review successor and executive-status ambiguity without looking at model probabilities.

Paired Brier (primary: calibrated recurrence vs global_recent) and log loss, country-history secondary, all on the same 195-code cohort; tie-aware budget 5/10/20 alerts can be added in a separate reviewed evaluator. With unknown labels, report coverage and sharp Brier/log-loss gain bounds over binary assignments, no complete-case point skill. With full coverage, report point gains and actual losses. This is one prospective cohort, not 195 independent years or a general claim of validated predictive skill. No changes to previous forecasts.

## Implementation boundary

The accompanying pure contract validates chronology, exact byte hashes and the code/label/probability schema, then computes paired gains. It takes explicit trusted expected hashes and a reviewed outcome mapping. It does NOT fetch, authenticate or independently admit any actual source or issue receipt, choose a vintage, verify sovereignty, derive outcome labels from raw events, or publish a forecast. Those steps are separate blockers. Synthetic tests only; no actual 2027 outcomes or probabilities in this branch.
