# Recovering the missing 2023 cohort: monthly-to-quarterly bridge

2026-11-24. Source-only protocol, before downloading or inspecting these new original data rows. Previous studies deliberately exclude 2023 because the official catalogue has 23.01.23.04 (Jan-Apr), not a Jan-Mar cumulative edition. The catalogue does list individual Jan, Feb and Mar 2023 originals. Their union is a different vintage construction and cannot silently replace the Q1 source.

Phase 1: census only of original monthly Candidate CSVs for Jan/Feb/Mar 2021, 2022, 2023, 2024, 2025; the cumulative Jan-Apr 2023 file; and first annual GED 24.1 original ZIP. Download exact official URLs, enforce sizes and schema, report SHA-256 and bytes and header/member names only; do not inspect event rows or annual outcomes. Existing quarterly SHA pins for 2021/22/24/25 remain unchanged. Freeze new source hashes before analysis. Block missing files, redirects and format mismatch.

Phase 2 (future, no results yet): compare monthly union with original Q1 for EACH control year, using identical 196 country IDs, state-based type 1, precision 1/2 and dates fully in Jan-Mar. Reject duplicate IDs within a source. Across monthly files use last eligible edition by month order, retain conflict counts in metadata; distinguish a changed date/type/country from a duplicated ID. Do not treat missing data as verified absence of violence. Assess total and country-level changes, risk-set changes at thresholds 1/5/10/25, and nonzero-Q1 feature changes. For 2023 compare union to Jan-Apr restricted to Jan-Mar as a sensitivity only; Jan-Apr cannot certify availability by April 30. For outcomes use first annual GED24.1, same May1-30/May1-Jul29 windows. Do not use any 2023 outcome for methodological choices. Historical first-publication dates are not certified; this remains retrospective.

Phase 3: use the harmonized monthly construction in every year, if original sources are available, as a separate full-panel experiment. Do not append 2023 monthly rows to the existing quarterly benchmark and call it homogeneous. Compare with previous quarterly benchmark and report differences in training/test composition. Retain all eight threshold/horizon combinations. No prospective issue or modification of prior 620 forecasts.

Source references: https://ucdp.uu.se/downloads/olddw.html and https://ucdp.uu.se/downloads/. All outputs aggregate/institutional, no individual event IDs or source text. Phase 1 CI prints only source metadata; no model scores.
