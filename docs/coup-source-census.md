# COUP research: source census before model fitting

Protocol 2026-11-25. New independent endpoint: country-year probability of at least one overt coup attempt, successful or failed, not conspiracy, not armed conflict incidence. No forecast issued. Proposed primary definition Powell–Thyne (illegal overt attempt by state elites to remove sitting executive); Cline Center is a separate sensitivity endpoint and not identical, especially conspiracies and auto-coups. Do not concatenate event lists or assume agreement.

Source-only stage: Powell author page https://jonathanmpowell.com/coups/ explicitly lists 2026-08-29 CSV and 2026-07-08 XLSX (current CSV includes tentative coding and warnings about future revisions); Cline institutional landing page and DataCite DOI 10.13012/B2IDB-9651987_V10 (v2.2.2) plus V8 (2.2.0), V9 (2.2.1). Verify exact raw bytes, hashes, schema, official link presence, archive bounds and version metadata without calculating any event outcomes. No event-level data redistributed. DOI metadata is not dataset bytes. If original download unavailable record blocked status, never silently substitute mirror. No country labels or event records printed. Subsequent stage must verify a dated at-risk country-year universe (not all modern countries in 1950), source-specific coding and dated edition coverage; no treating missing country-years as zeros. Preregister fixed rolling evaluation and simple controls before computing outcomes. Historical revised editions are not historical as-of data; cross-vintage comparisons are necessary but do not by themselves prove publication-time eligibility. No changes to 620 earlier country-questions or 1,304 DEC2026 country-scenarios.
